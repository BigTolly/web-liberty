# Web Liberty (расширение для Chrome и Firefox)

Управляйте несколькими прокси-серверами SOCKS5 / SOCKS4 / HTTP / HTTPS и переключайтесь между ними одним кликом. Опциональная маршрутизация через белый/чёрный список доменов. Светлая/тёмная тема следует настройкам ОС.

## Возможности

- Добавление неограниченного числа профилей (`socks5`, `socks4`, `http`, `https`).
- Переключение между профилями или режимом **Direct** (без прокси) в один клик.
- Опциональная аутентификация для HTTP(S)-прокси (автоматически через `webRequest.onAuthRequired`).
- Режимы фильтрации доменов:
  - **All websites are allowed** — прокси используется для всех сайтов.
  - **Whitelist only** — прокси используется **только** для указанных доменов.
  - **Blacklist deny** — прокси используется для всего, **кроме** указанных доменов.
- Иконка на панели инструментов отражает текущее состояние (вкл/выкл); без лишних подписей.
- Светлая/тёмная тема в зависимости от системной.
- Шаблоны доменов поддерживают голые домены (совпадение по поддомену) и wildcards `*`, например: `example.com`, `*.github.com`, `*google*`.
- Локальные/приватные адреса (RFC1918, loopback, `*.local`) всегда используют прямое соединение.
- Экспорт / импорт конфигурации в формате JSON.

## Установка

Скачайте репозиторий (кнопка **Code → Download ZIP** на GitHub) и распакуйте архив. Для каждого браузера есть своя папка: `chrome/` и `firefox/`. Выберите инструкцию для вашего браузера.

### Chrome (режим разработчика)

1. Скопируйте содержимое папки `chrome/` в постоянное место, например: `C:\Users\<ВАШЕ_ИМЯ>\Documents\Chrome Extensions\WebLiberty`. Не удаляйте и не переносите эту папку после установки: Chrome читает файлы расширения прямо из неё.
2. Откройте `chrome://extensions/`.
3. Включите **Режим разработчика** (правый верхний угол).
4. Нажмите кнопку «Загрузить распакованное расширение» и выберите папку `WebLiberty`.
5. Закрепите расширение. Нажмите на иконку → ⚙ для открытия настроек.

### Firefox (версия 140 и новее)

1. Скачайте файл `web-liberty.xpi` из папки `firefox/`.
2. Откройте `about:addons`, нажмите на шестерёнку → «Установить дополнение из файла…» и выберите скачанный `.xpi`. Можно также перетащить файл в окно Firefox.
3. Подтвердите запрошенные разрешения.
4. Закрепите расширение на панели инструментов. Нажмите на иконку → ⚙ для открытия настроек.

По умолчанию Firefox не запускает расширения в приватных окнах. Если нужно, разрешите это в настройках расширения на странице `about:addons`.

## Использование

Работа расширения одинакова в Chrome и Firefox.

1. **Всплывающее окно**: выберите активный сервер или режим **Direct**. Кнопка **+ Add proxy** открывает страницу настроек для добавления нового прокси. Кнопки **Edit** рядом с *Whitelist only* / *Blacklist deny* открывают соответствующий список доменов.
2. **Страница настроек**: добавьте один или несколько прокси-серверов (название, протокол, хост, порт, логин/пароль — опционально). Радио-кнопка **Active** в таблице отмечает, какой профиль сейчас применяется; если ничего не отмечено — режим Direct.
3. **Фильтр доменов**: выберите режим и отредактируйте списки. Голый домен совпадает с поддоменами; поддерживается wildcard `*`.

## Примечания по протоколам

- `socks5` — в Chrome DNS может разрешаться удалённо прокси-сервером в зависимости от политики браузера; в Firefox имена всегда разрешаются на стороне прокси.
- `socks4` — аутентификация протоколом SOCKS4 не поддерживается.
- `http` / `https` — логин и пароль отправляются автоматически, когда прокси отвечает статусом `407`.
